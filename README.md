# Homebrew Tap for QueryMind

This is the official Homebrew tap for [QueryMind](https://app.querymind.dev), an AI-powered database management desktop app.

## Installation

```bash
brew tap QueryMind-dev/querymind
brew install --cask querymind
```

## Upgrade

```bash
brew upgrade --cask querymind
```

## Uninstall

```bash
brew uninstall --cask querymind
```

## Requirements

- macOS Monterey (12.0) or later
- Apple Silicon (M1/M2/M3)
